# java-racingcar-precourse

# 구현할 기능 목록

- [ ] 입력
  - [ ] 입력 값 검증
- [ ] 출력
  - [ ] 실행 결과 출력(1 반복에 1번씩 출력)
  - [ ] 최종 우승자 출력
- [ ] Race
  - [ ] Car 등록
  - [ ] 실행 횟수만큼 레이스
  - [ ] 현재 상황 확인
  - [ ] 우승자 확인
- [ ] Car
  - [ ] 현재 이동거리 확인
  - [ ] 이동 or 정지

# 구현 목표

- 확장 가능한 구조
- 테스트 주도 개발
- 1기능 1커밋
- 추상화를 이용한 느슨한 결합
